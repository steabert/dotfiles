# Setup

## Software

Depending on the distribution, some stuff is easier to install through the
package manager. Here is a list of software that could be more tricking to
obtain that way, check their docs for recommended installation on your distro.

It's best to install programming support first, as it can be used to
easily compile or install other tooling.

Programming:
- Go: [go](https://go.dev/dl/)
- Go debugger: [delve](https://github.com/go-delve/delve)
- Go debugger GUI: [gdlv](https://github.com/aarzilli/gdlv)
- Go LSP: [gopls](https://go.dev/gopls/)
- Rust: [rust](https://rust-lang.org/learn/get-started/)
- Rust LSP: [rust-analyzer](https://github.com/rust-lang/rust-analyzer)
- GDB GUI: [gf](https://github.com/nakst/gf)
- JavaScript:
  - [node](https://nodejs.org/en)
  - [deno](https://github.com/denoland/deno/)
- Zig: [zig](https://ziglang.org/download/)
- Zig LSP: [zls](https://github.com/zigtools/zls)

General:
- Finding files: [fdfind](https://github.com/sharkdp/fd)
- Regex search: [ripgrep](https://github.com/BurntSushi/ripgrep)
- Regex replace: [fastmod](https://github.com/facebookincubator/fastmod)
- Editor: [helix](https://docs.helix-editor.com/install.html)
- Fonts: [iosevka](https://github.com/be5invis/Iosevka/releases)
- Terminal:
  - [kitty](https://sw.kovidgoyal.net/kitty/)
  - [ghostty](https://ghostty.org/download)
- Keyboard: [UHK](https://ultimatehackingkeyboard.com/agent)
